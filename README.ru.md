# ReproShot

**Превратите любую падающую команду в воспроизводимый отчёт об ошибке.**

```bash
npx reproshot -- npm test
```

![Карточка ReproShot из настоящего демонстрационного запуска](docs/reproshot.svg)

> **Предварительная версия:** ReproShot пока не опубликован в npm. До первого релиза установите его из исходников.

ReproShot запускает команду, показывает её вывод в терминале и сохраняет полезный для отладки контекст в локальную папку. Никаких аккаунтов, загрузки данных или внешних сервисов.

## Попробовать

Для работы нужен Node.js 20 или новее. Поддерживаются Windows, Linux и macOS. До первого npm-релиза:

```bash
git clone https://github.com/t1ktakdev/ReproShot.git
cd ReproShot
npm ci --ignore-scripts
npm run build
npm link
```

После этого запустите ReproShot в проекте, который нужно отладить:

```bash
reproshot -- npm test
reproshot -- pnpm build
reproshot -- cargo test
reproshot -- pytest
```

Команда запускается напрямую, без дополнительной оболочки, поэтому границы аргументов сохраняются. Если нужны конвейеры или другой синтаксис shell, запустите нужную оболочку явно.

## Что сохраняется

Каждый запуск создаёт папку внутри `.reproshot/`:

```text
report.md
report.html
reproshot.svg
manifest.json
reproduce.sh
reproduce.ps1
stdout.log
stderr.log
changes.patch
SHA256SUMS
```

В отчёт входят команда, код завершения, версии используемых инструментов, состояние Git, очищенные логи и скрипты для повторного запуска. `changes.patch` добавляется, если есть подходящие отслеживаемые текстовые изменения. Исходный код и зависимости в папку отчёта не копируются.

Полный отчёт можно открыть в `report.html`, а `reproshot.svg` удобно использовать как краткую сводку. Для повторного запуска восстановите указанную ревизию, установите зависимости проекта и запустите подходящий скрипт из папки проекта. Перед применением патча обязательно просмотрите его.

Repro Score показывает, насколько полно собраны полезные данные. Он не гарантирует, что ошибку удастся воспроизвести.

Чтобы получить текст для GitHub issue:

```bash
reproshot issue                         # последний отчёт в этом проекте
reproshot issue .reproshot/<capture-id> # конкретный отчёт
```

Команда выводит Markdown, который можно проверить и вставить вручную. На GitHub она ничего не отправляет. Для скриптов и CI добавьте `--json` перед `--`, чтобы получить машиночитаемую сводку.

## Перед публикацией отчёта

ReproShot скрывает обнаруженные секреты, но автоматическая проверка не может найти всё. Проверьте отчёт перед публикацией. Вывод команды в терминале не изменяется, поэтому в нём могут остаться напечатанные командой секреты.

ReproShot не читает `.env`, SSH-ключи, хранилища учётных данных, данные браузера или посторонние файлы. Содержимое неотслеживаемых файлов не включается. Если вы используете ReproShot регулярно, добавьте `.reproshot/` в `.gitignore`.

Точные правила сбора, ограничения, обработка процессов, коды завершения и расчёт Repro Score описаны в [capture contract](docs/capture-contract.md).

## Разработка

```bash
npm run check
npm run demo
```

SVG выше создан из сохранённого демонстрационного запуска ReproShot. Примеры намеренно завершаются с ошибкой, чтобы проверить весь процесс создания отчёта.
